# ESLAM SAMEH — Portfolio Starter

واجهة أولية لبورتفوليو شخصي بتصميم Modern Dark، باللغة العربية، ومتجاوبة مع الموبايل والكمبيوتر.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` مباشرة في المتصفح.

لا يحتاج هذا الإصدار إلى تثبيت Node.js أو أي مكتبات.

## ملاحظات مهمة
- هذه نسخة الواجهة الأولى (Frontend Prototype).
- زر معاينة الإدارة مجرد تنبيه توضيحي؛ لم يتم بعد ربط تسجيل الدخول أو لوحة الإدارة الحقيقية.
- الإحصائيات المعروضة رمزية وليست أرقام زيارات حقيقية.
- البريد `hello@example.com` تجريبي ويجب استبداله ببريدك.
- بطاقات المشاريع والمهارات نصوص مبدئية قابلة للتعديل.

## المرحلة التالية
تحويل الواجهة إلى Next.js، ثم ربط Supabase للمصادقة وقاعدة البيانات، وإنشاء لوحة Admin حقيقية، ومركز إشعارات وإحصائيات مبنية على بيانات فعلية.
